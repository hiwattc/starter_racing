# Kart Rush

주인공 1명 vs AI 10대가 3랩을 겨루는 three.js 레이싱 게임.
[mrdoob/Starter-Kit-Racing](https://github.com/mrdoob/Starter-Kit-Racing) (MIT)의 차량 물리 · 트랙 · 사운드 · 카메라를 기반으로 확장했습니다.

## 실행

ES 모듈이므로 로컬 서버가 필요합니다.

```bash
python3 -m http.server 8791
# 브라우저에서 http://localhost:8791
```

`?demo`를 붙이면 바로 시작하고 내 차도 자동주행합니다 (`http://localhost:8791/?demo`).

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D / 방향키 | 주행 |
| Shift (또는 K) | 터보 – 게이지 소모, 드리프트하면 더 빨리 충전 |
| Space (또는 J) | 아이템 사용 |
| R | 트랙 중앙으로 복귀 |
| Enter | 시작 / 결과 화면에서 재시작 |

게임패드(A 터보, X/B 아이템, Y 복귀)와 터치(가상 조이스틱 + TURBO/ITEM 버튼)도 지원합니다.

## 코스

시작 화면에서 고를 수 있습니다 (URL `?course=forest|speedway|canyon`으로 바로 지정도 가능).

| 코스 | 특징 |
| --- | --- |
| 포레스트 서킷 | 균형 잡힌 기본 코스 (30칸) |
| 선셋 스피드웨이 | 긴 직선 + 시케인, 노을 조명 – 터보 승부 (30칸) |
| 트와일라잇 캐년 | 헤어핀·S자 연속 14코너, 황혼 조명 – 테크니컬 (32칸) |

새 코스는 `js/TrackPath.js`의 `COURSES`에 셀 좌표 루프로 추가합니다 (첫 칸 = 결승선, 마지막 칸은 출발 그리드용 직선).

## 기능

- **AI 10대** – 각자 실력·공격성이 다르고, 레인을 바꿔 추월·회피하며, 직선에서 터보를 쓰고, 상황에 맞게 아이템을 사용합니다. 벽에 끼면 후진해서 빠져나옵니다. 러버밴딩으로 접전이 유지됩니다.
- **차량 충돌** – 범퍼카처럼 튕겨나가는 반발력, 충돌 강도에 비례한 불꽃 파티클, 차체 번쩍임, 카메라 흔들림, 충돌음. 측면 충돌은 차를 비틀고, 벽 긁힘에도 불꽃이 튑니다.
- **터보** – 게이지형 니트로. 사용 중 최고속도 1.5배, 배기 화염, 시야각 확대, 속도선 효과.
- **아이템 박스** (트랙 5곳 × 5개, 2초 후 재생성) – 순위가 낮을수록 좋은 아이템이 잘 나옵니다.
  - 🔥 부스터 – 짧고 강력한 가속
  - 🛡️ 실드 – 6초 무적, 부딪힌 상대를 튕겨내고 스핀시킴, 미사일 1회 방어
  - 🚀 유도 미사일 – 트랙을 따라 날아가 바로 앞 순위 차량을 추적, 명중 시 스핀 + 공중으로 튕김
  - 🛢️ 오일 – 뒤에 떨어뜨리면 밟은 차가 스핀
  - ⚡ 터보 충전 – 터보 게이지 100% + 짧은 부스트
- **레이스 진행** – 3·2·1 카운트다운, 실시간 순위, 랩/베스트랩, 미니맵, 역주행 경고, 미사일 접근 경고, 결과 화면.

## 구조

| 파일 | 설명 |
| --- | --- |
| `js/main.js` | 씬 구성, 레이스 상태, 충돌 처리, 메인 루프 |
| `js/TrackPath.js` | 서킷 레이아웃(셀 루프) → 트랙 피스 생성, AI용 중심선 웨이포인트 |
| `js/AIDriver.js` | AI 조향 · 가속 · 회피 · 터보 · 아이템 판단 |
| `js/Items.js` | 아이템 박스, 미사일, 오일, 실드 |
| `js/Effects.js` | 불꽃 · 화염 · 폭발 파티클 |
| `js/Sfx.js` | 합성 효과음 (픽업, 부스트, 폭발 등) |
| `js/HUD.js`, `css/hud.css` | 순위 · 랩 · 아이템 · 터보 게이지 · 미니맵 · 결과 화면 |
| `js/Vehicle.js` 외 | 원본 스타터킷 모듈 (부스트/스핀/틴트 등 확장) |
